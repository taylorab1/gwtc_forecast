# Working instructions for students and coding agents

Read README, SCIENCE_CHARTER, KNOWN_GAPS and the current assigned milestone before changing code. Current authority is v0.5, not archived v0.4 plans. The matched-feature redesign was explicitly requested; production, unfrozen prior choices and expensive campaigns were not automatically authorized.

Work -> evidence -> next scientific decision -> defensible claim or stop/narrow decision. Optimize that chain, not file count, code volume, tests passed, agent agreement or a favorable score.

Preserve scientific invariants: training/held-out separation; matched shared assumptions; coordinate/prior/selection conventions; count-conditioned joint prediction; meaningful priors once frozen; declared randomness/trial counts; numerical criteria and negative branches. Candidate prior values remain development choices requiring review. Do not bypass a missing release convention with an undocumented approximation.

Operate autonomously inside those boundaries: inspect current local inputs/jobs, implement a small end-to-end task, test known answers, repair ordinary defects, save/reload evidence and report. Use the simplest adequate APIs/checkpoints. Reuse valid computations after packaging failures. Do not repeatedly re-download, retrain or mint new scientific campaigns for operational retries.

Default to local tests and small synthetic work. Keep code/Conda local and real data/results external. Use a representative producer-to-report benchmark before long work. Do not claim background persistence or completion without evidence. Check running jobs before launching duplicates. Never overwrite unrelated local changes or the only copy of an attempt.

Claims must distinguish implemented, executed and scientifically validated. A valid unfavorable result completes its task. Inconclusive evidence is not a pass; invalid computation is not negative science. A simple blocked-input report is preferable to fabricated release mappings.

Return scientific result/uncertainty first, interpretation/limit, validation, small inspectable evidence and a next recommendation separated from authorization. Codex use is optional for students. Every student owns the methods and must explain/check their contribution independently.
