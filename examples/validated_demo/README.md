# Synthetic build reference (not real GW evidence)

These are the small results of the completed v0.5 build demonstration and 20-per-direction repeated-training experiment. Every figure is labeled synthetic. The demo used 40 training events and 24 held-out events in each of two toy periods. Twenty conditional-power trials per direction are illustrative only. The separate calibration regenerates and refits training on each replicate. Neither qualifies realistic power or the full BBH inference path.

Bulk simulated HDF5 contracts and factor arrays are omitted from the code archive; rerun the README commands to regenerate them outside the repository. Exact execution context and checks are in ../build_evidence and ../../VALIDATION.md. One earlier release-run attempt timed out before completion; it was not used as scientific evidence. The completed retry retained the same scientific configuration and added phase progress reporting.
