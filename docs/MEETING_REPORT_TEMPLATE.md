# Meeting report (one page, per student)

**Student / meeting / date / agreed research hours:**

**Scientific question:** One sentence.

**Result:** One or two quantitative findings, including uncertainty or numerical tolerance. State SYNTHETIC, REAL-INPUT VALIDATION, or REAL SCIENTIFIC RESULT explicitly.

**Evidence:** Exact rerun command, relevant input/configuration, code revision or local changes, saved report path and one figure/table. Provide the actual small files when the reviewer lacks access to the computer.

**Independent check:** Analytical answer, quadrature, released reference or genuinely separate implementation; expected and obtained agreement. State what has not been checked.

**Interpretation and limit:** What this establishes; what it does not establish. Distinguish invalid/incomplete computation, qualified low power, and an unfavorable scientific result.

**Blocker (only when present):** Minimal reproducer, expected/actual output, attempted fixes, time first reported, and the specific help or scientific decision needed.

**Next commitment:** One bounded deliverable with an agreed date. Identify any advisor-owned prerequisite.

**At the meeting:** Explain the equation and make one small predicted modification without relying on generated explanations. Peer review checks reproducibility, not whether both students obtained the desired sign.
